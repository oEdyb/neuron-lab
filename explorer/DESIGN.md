# Take D — Tower then plane

Black (#000), warm ivory (#eeeae3), amber (#ffc17a), quiet warm-grey dividers. Arial for actions; system monospace for coordinates and measurements. No hero copy, decorative particles, dashboard cards, floating search bar or permanent favourites panel.

The signature is the transition: B's actual 24-layer WebGL tower rotates into the chosen horizontal layer, then resolves into a pixel-aligned 2D neuron plane. The left rail is a thin, clickable tower silhouette. A stable right inspector replaces layer facts with neuron facts without covering the dots.

B supplies the proven tower, camera interpolation, measured data and model bridge. C supplies the principle of an integer-spaced grid; D renders individual circles rather than a density raster. Linear supplies `/` global search and coordinate navigation; Raycast supplies the centered command-palette layout, keyboard navigation and one results surface. Reference screenshots inherited in refs/; original B/C and A screenshots inspected before implementation.

Every dot remains individually selectable. Grid arrow keys move between neighbouring neurons; global arrows switch layers. Enter opens the tower's default L12. Escape returns to the tower. Cmd/Ctrl+K or / opens the unified search/favourites palette.

Semantic search uses 53,820 WordNet synonym sets plus explicit multilingual concept groups. No inference runtime, CDN or GPU. Matched source words are printed in every result. Concept-first diversification surfaces synonyms instead of filling every row with the literal query. This is lexical semantic expansion, without sentence embeddings or word-sense disambiguation.

Sources: https://linear.app/docs/search, https://linear.app/docs/favorites, https://wordnet.princeton.edu/. WordNet license ships in data/WORDNET-LICENSE.txt.
